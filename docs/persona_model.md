# 1. Introduction

The Persona Data Model defines the structure of every synthetic persona generated by the platform.

A standardized model ensures consistency across all modules including persona generation, memory management, surveys, interview mode, analytics, and future AI agents.

---

# 2. Persona Overview

Each persona represents a synthetic user with realistic demographic, behavioural, psychological, and product-related attributes.

The persona model acts as the central data structure shared across all system components.

---

# 3. Persona Schema

| Category | Attributes |
|----------|------------|
| Basic Information | Name, Age, Gender |
| Professional | Occupation, Education, Income |
| Demographics | Location, Family Status |
| Behaviour | Lifestyle, Technology Usage |
| Personality | Traits, Behaviour Patterns |
| Goals | Personal Goals |
| Pain Points | Challenges |
| Product Behaviour | Buying Behaviour, Preferences |
| Psychological Profile | Motivation, Decision Making |
| Memory | Previous Conversations *(Milestone 2)* |
| Survey | Survey Responses *(Milestone 2)* |
| Analytics | Product Fit Score *(Milestone 3)* |
