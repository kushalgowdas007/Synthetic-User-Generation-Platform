# Synthetic User Generation Platform

# Mentor Presentation Notes

---

# 1. Project Introduction

Good morning, everyone.

Our project is **Synthetic User Generation Platform**, an AI-powered application that generates realistic synthetic user personas using Google Gemini AI and Faker.

The objective is to help product teams perform user research without collecting real user data.

---

# 2. Problem Statement

Traditional user research requires:

- Time
- Cost
- Real participants

Our platform creates realistic AI-generated personas that can be used for:

- Product Research
- UX Testing
- Behaviour Simulation
- AI Experiments
