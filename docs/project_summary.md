# Project Objective

The Synthetic User Generation Platform is designed to generate realistic synthetic user personas using Large Language Models (Google Gemini AI) and structured behavioural modelling.

The generated personas help product teams, UX researchers, designers, and developers perform user research without requiring real users or exposing personal information.

---

# Problem Statement

Traditional user research is:

- Expensive
- Time consuming
- Difficult to scale
- Dependent on real participants

Our platform solves this by automatically generating diverse AI-powered synthetic personas that realistically simulate different user types.
